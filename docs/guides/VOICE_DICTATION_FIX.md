# Voice Dictation Fix

Use this guide to fix audio feedback issues during mobile dictation. This happens when Wispr Flow or the device speech system plays back audio that gets picked up again and pollutes the message you are trying to send to an agent.

## Fastest Fixes

1. Turn off **Voice Feedback** in Android accessibility or speech settings.
2. Switch to **Google Keyboard (Gboard)** for voice input.
3. If you need the cleanest result, use **Google Docs voice typing** first, then copy the text into Telegram.

## Recommended Option

If repeated dictation errors are blocking work, stop using live voice-to-Telegram dictation and switch to the templates in [`COPY_PASTE_COMMANDS.md`](./COPY_PASTE_COMMANDS.md).

## Step-by-Step

### Option 1: Disable voice feedback

1. Open Android **Settings**.
2. Search for **Voice Feedback**, **Spoken Feedback**, or speech accessibility settings.
3. Turn the feature off.
4. Test dictation again in Telegram.

### Option 2: Use Gboard voice typing

1. Install or enable **Gboard**.
2. Set it as the active keyboard.
3. Use the microphone button in Gboard instead of the existing dictation path.
4. Review the text before sending it to the agent.

### Option 3: Use Google Docs voice typing

1. Open Google Docs on mobile or desktop.
2. Dictate the message there.
3. Review and correct the text.
4. Copy the final text into Telegram.
5. Send it to the agent.

## Best Practice

For urgent operations, prefer typed or pasted commands over voice input. It is faster, cleaner, and avoids accidental transcription of app audio.
