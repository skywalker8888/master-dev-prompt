# Copy-Paste Commands

Use these templates when mobile voice transcription is unreliable. Copy one, replace the placeholders, and send it directly to the agent.

## Daily Operations

- `@agent: give me daily report`
- `@agent: process refund for [email] - Amount: [amount]`
- `@agent: check status for order [order_id]`
- `@agent: send follow-up to [customer_name] about [topic]`

## Weekly / Monthly

- `@agent: give me weekly report`
- `@agent: summarize this month’s open issues`
- `@agent: list unresolved refunds from this week`

## FAQ & Support

- `@agent: add to FAQ - Question: [question] - Answer: [answer]`
- `@agent: draft support reply for [issue]`
- `@agent: summarize customer complaint from [email]`

## Pricing & Policy

- `@agent: check pricing for [product]`
- `@agent: explain refund policy for [product]`
- `@agent: approve change request number [#]`

## Product-Specific

The examples below use labels from an existing support workflow. Replace them with your own product or team names if they do not apply.

### APEX WOLF

- `@agent: create APEX WOLF update for [customer/company]`

### Higgsfield

- `@agent: summarize Higgsfield request from [email]`

### Track Record

- `@agent: prepare Track Record follow-up for [customer/company]`

## Real Examples

- `@agent: process refund for alex@example.com - Amount: 49.00`
- `@agent: add to FAQ - Question: Do you support Android? - Answer: Yes, Android is supported.`
- `@agent: approve change request number 142`

## How to Use on Mobile

1. Open this guide.
2. Select the command you want.
3. Copy it.
4. Open Telegram.
5. Paste it.
6. Send it to the agent.

## Why This Works

- No voice transcription problems
- Agent instructions stay clear
- Most requests take about 10 seconds to send
