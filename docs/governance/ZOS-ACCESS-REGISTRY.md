## 2) Purpose
This registry tracks credential ownership, access scope, authentication strength, and review status for ZOS systems.

## 3) Constitutional Compliance Statement
This document shall not redefine governance established by ZOS-CON-0001. Where conflict exists, ZOS-CON-0001 prevails.

## 4) Data Handling Rule
The Access Registry stores metadata only. It must never contain passwords, private keys, recovery codes, or API-secret values.
